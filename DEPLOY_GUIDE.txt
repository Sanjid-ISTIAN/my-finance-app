## 🔐 Authentication Help

When you run git push, GitHub will ask for authentication:

### Option A: Personal Access Token (Recommended)
1. Go to: https://github.com/settings/tokens
2. Click "Generate new token"
3. Name it: "daily-expense-tracker"
4. Select scopes: check "repo" (all) and "workflow"
5. Scroll down and click "Generate token"
6. **Copy the token immediately** (you won't see it again)
7. When git asks for password, paste this token

### Option B: GitHub CLI
Run: \gh auth login\ and follow prompts

## ❓ Troubleshooting

### "Not found" after enabling Pages?
- Wait 2-3 minutes
- Clear browser cache
- Check that index.html is in root directory

### Pages section not visible?
- Make sure repository is PUBLIC
- Go to Settings → General
- Scroll down to "Danger Zone" to check visibility

### Authentication failed?
- Make sure Personal Access Token has "repo" scope
- Token might have expired (create new one)
- Try GitHub CLI: \gh auth login\

### Charts not showing?
- Check internet connection (Chart.js loads from CDN)
- Open browser console (F12) for errors
- Wait for Chart.js to load
